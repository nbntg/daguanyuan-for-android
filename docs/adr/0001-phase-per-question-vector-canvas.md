# 分阶段建设每题矢量无限画布

每道题采用独立的矢量无限画布，以题目卡片、按需显示的解析卡片、文字笔记卡片和手写笔迹组成复盘空间。首版优先保证低延迟书写、压感、像素橡皮、整笔套索、自动保存和所见即所得导出，以免一次实现接近完整笔记软件而损害稳定性。编辑范围后来由 ADR 0002 进一步收紧，不再规划局部笔迹切割和完整画布备份。

## Considered Options

- 首版一次实现全部高级编辑能力。
- 先建立可扩展的矢量数据模型，再分阶段开放编辑能力。

## Consequences

首版即可完成真实做题和复盘；矢量底层从第一阶段建立，以支持压感、像素橡皮、整笔套索、撤销重做和稳定保存，而不是为后续扩张成综合笔记软件预留承诺。
