# 保持书写画布的基础编辑范围

书写画布继续使用每题独立的矢量数据，但编辑范围保持克制：

- 卡片与套索相交即整张选中。
- 笔迹有采样点进入套索即整笔选中。
- 不切割矢量笔迹的局部片段。
- 选区只提供移动、缩放、创建副本和删除。
- 不提供复制、剪切和粘贴。
- 优先保证低延迟、连续弧线、压感、橡皮和稳定保存。

未来增强只在原站状态写回和已知设备兼容两类需求中继续投入。OCR、自动修形、图层、复杂套索、批量导出和完整画布备份不在规划中。

## Considered Options

- 继续把画布扩展为具备局部笔迹切割、复杂图层和完整备份的综合笔记软件。
- 保留矢量底层，但只实现真实做题所需的基础编辑和流畅书写。

## Consequences

实现和真机验证可以聚焦于做题、批注与复盘，降低撤销重做、压感曲线、橡皮和文件兼容被高级编辑破坏的风险。用户无法只移动一条笔画中的局部片段，也无法通过系统式剪贴板复制画布对象；需要重复内容时使用“创建副本”。
